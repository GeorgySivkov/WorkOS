# WorkOS

Личная операционка George: всё входящее (почта, Slack, Trello, календари, записи встреч Plaud,
Альфа через ActiveSync и А-Чат) ложится в одну базу Postgres, а модель разбирает его на задачи,
обещания, черновики и план дня. Разговаривает система через Telegram-бота с темами и мини-приложение
«Квесты». Наружу ничего не уходит без нажатия кнопки George.

## Где что лежит

| Каталог | Что там |
|---------|---------|
| `core/` | конфиг, база, вызов модели (claude CLI), Telegram, время, эмбеддинги |
| `collectors/` | коллекторы источников, EAS (Альфа), приём событий с Мака |
| `extract/` | люди и имена, решения и обещания со встреч, триаж входящих |
| `agents/` | план дня, расстановщик, драфтер, бриф, разбор недели, аудит, автономия, бэкфилл эмбеддингов |
| `bot/` | бот-терминал: захват, карточки одобрения, план, «Спросить», «Кто это?» |
| `app/` | мини-приложение (API и статика) |
| `executors/` | исполнители одобренного: календарь, Trello, Slack, черновики Gmail (без модели) |
| `rpg/` | персонаж: сетка, опыт, Garmin, недельный итог |
| `migrations/`, `schema.sql`, `migrate.py` | схема и права ролей базы |
| `deploy/` | install.sh, включение по фазам, systemd, бэкап и проверка восстановления, шаблоны .env |
| `mac/`, `tools/` | коллектор А-Чата и одноразовые скрипты для Мака (Google OAuth, модель эмбеддингов) |
| `style/` | корпус стиля для черновиков от имени George |
| `tests/` | автотесты на локальном Postgres |

Одна точка входа для таймеров и ручных запусков: `workctl.py` (`python3 workctl.py --help`).
