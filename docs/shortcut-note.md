# Команда «Заметка»: голос с часов во «Входящие» WorkOS

Цепочка: fenix 8 (кнопка голосового ассистента) → Siri на айфоне → команда «Заметка» →
диктовка → POST на приёмник дроплета по Tailscale → бот размечает заметку и отвечает во «Входящие».
Аудио не передаётся, только текст диктовки.

## Подготовка (один раз)
1. На дроплете применить миграцию 015 и включить источник:
   `UPDATE work.sources SET enabled = true WHERE id = 'ios:notes';`, перезапустить `workos-bot`
   (приёмник `workos-ingest` перезапускать не нужно, он читает источники из базы).
2. На айфоне: Tailscale подключён (тем же аккаунтом, что дроплет); Siri → язык «Русский»
   (Настройки → Siri → Язык). Диктовка в команде берёт язык из своего параметра, но имя команды
   Siri понимает на своём языке.
3. На часах: Настройки → Телефон → Голосовой ассистент включён; назначить кнопку
   (по умолчанию удержание верхней левой кнопки или по назначению «Горячие клавиши»).

## Команда в «Командах» (iOS)
Название: **Заметка** (так её зовут голосом: «Siri, заметка»).

Действия по порядку:
1. **Надиктовать текст** (Dictate Text) · Язык: Русский · Остановить прослушивание: После паузы.
2. **Текст** (Text): `{"now": "[Текущая дата]", "text": "[Надиктованный текст]"}`
   - `[Текущая дата]`: вставить переменную «Текущая дата», формат: ISO 8601, с временем.
   - Если в тексте возможны кавычки, вместо «Текст» использовать «Словарь» (Dictionary)
     с ключами `now` и `text`, а в «Получить содержимое URL» Тело запроса = Словарь (JSON).
3. **Получить содержимое URL** (Get Contents of URL)
   - URL: `http://<tailnet-ip>:8788/ingest/ios:notes`
   - Метод: POST · Заголовки: `Authorization: Bearer <INGEST_TOKEN>`, `Content-Type: application/json`
   - Тело запроса: Файл → переменная «Текст» из шага 2 (или Словарь из шага 2).
4. **Получить значение по ключу** `inserted` из «Содержимое URL» (Get Dictionary Value).
5. **Если** значение = 1 → **Показать уведомление** «Записал» (с часов уведомление читает Siri),
   иначе → «Не ушло: {Содержимое URL}».

Проверка с айфона без часов: запустить команду вручную, сказать «позвонить в банк в пятницу»,
во «Входящих» через ~20 с появится 🎙 с разметкой (Задача · пт …) и кнопками поправки.

Ограничения: Siri с часов работает только при связи часов с айфоном по Bluetooth;
без интернета на айфоне команда выдаст «Не ушло», заметку надо повторить позже (повтор
с тем же временем и текстом не дублирует запись).
